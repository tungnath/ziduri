# 13 — Engineering Standards
HTML: semantic elements, valid nesting, accessible labels, descriptive links and logical heading hierarchy.

CSS: tokens/custom properties, controlled specificity, mobile-first responsive rules.

JavaScript: ES modules, small modules, defensive error handling, no unnecessary globals.

Security: no secrets in repositories; sanitize untrusted content; minimize third-party scripts; review permissions.

Performance: establish budgets; optimize images, fonts, scripts and third-party requests; avoid blocking resources.

Testing: smoke-test critical pages, responsive behavior, keyboard navigation, links, metadata and production builds.
