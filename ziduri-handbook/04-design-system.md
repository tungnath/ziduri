# 04 — Design System
Support automatic light/dark theme using prefers-color-scheme plus a persistent user override.

Define CSS custom-property tokens for typography, spacing, radii, borders, surfaces, text hierarchy, shadows, accents, focus states and motion.

Reusable components:
Header, Footer, Button, Link, Badge, Card, ProductCard, Hero, FeatureGrid, FAQ, Breadcrumb, Callout, ScreenshotGallery, ArticleCard.

Respect prefers-reduced-motion. Animations must communicate state or hierarchy rather than decorate every interaction.
