# 11 — Product Release Playbook
Before release:
- identity/slug finalized
- landing page complete
- privacy policy accurate
- documentation complete
- screenshots optimized
- accessibility reviewed
- mobile reviewed
- SEO metadata reviewed
- structured data validated
- analytics events defined
- store listing ready
- support path available

Release:
deploy → verify HTTPS → verify canonical → verify robots → verify sitemap → verify product/privacy/store links → request indexing.

Post-release:
monitor Search Console, analytics and errors; improve based on genuine user behavior and queries; update changelog.
