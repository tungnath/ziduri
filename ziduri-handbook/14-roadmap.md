# 14 — Ziduri Technical Roadmap
Stage 1: static site, GitHub Pages, custom domain, design system, SEO foundation, privacy framework, first product.

Stage 2: blog, documentation, changelogs, analytics, Search Console monitoring.

Stage 3: reusable product metadata/build pipeline; migrate to Astro when static-site complexity makes it worthwhile.

Stage 4: authentication, payments, APIs, AI agents, MCP, local AI, PWA or server functionality only for products that need them.

Do not adopt infrastructure because it is fashionable; adopt it when requirements justify the complexity.
