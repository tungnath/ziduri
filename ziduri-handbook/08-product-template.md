# 08 — Product Page Specification
Every product uses a reusable page model.

Required sections:
1. Breadcrumb
2. Product name/value proposition
3. Primary CTA
4. Screenshot/demo
5. Problem
6. Solution
7. Features
8. How it works
9. Audience/use cases
10. FAQ
11. Installation/download
12. Privacy
13. Documentation
14. Changelog
15. Related products

Metadata model:
name, slug, shortDescription, longDescription, category, platforms, primaryKeyword, secondaryKeywords, storeUrl, privacyUrl, documentationUrl, changelogUrl, icon, screenshots, releaseStatus.

Generate title, description, canonical, social metadata and valid structured data from product metadata.
