# Ziduri Product Studio Handbook
Version 1.0 — August 2026

Ziduri is a collection of lightweight daily-use productivity software utilities.

This handbook is the single source of truth for architecture, design, SEO, deployment, privacy, content, releases, and AI-assisted development across Ziduri products.

## Portfolio
Browser Extensions · Android Apps · Desktop Applications · Developer Tools · AI Tools · Plugins · SaaS

## Audiences
Developers · Students · Office Professionals · Businesses · General Consumers

## Brand
Elegant, modern, refined and premium. Inspired by the design quality of Stripe: sophisticated typography, restrained gradients, subtle depth, clear hierarchy and polished micro-interactions.

## Technology evolution
Phase 1: semantic HTML/CSS/vanilla JS + GitHub Pages.
Phase 2: Astro when reusable static generation becomes valuable.
Phase 3: Next.js only when SSR/dynamic application requirements justify it.

## Agent rule
Read the relevant handbook chapters before implementation. Preserve public URLs, SEO conventions, privacy accuracy, accessibility, performance and existing architecture unless a change is explicitly justified.
