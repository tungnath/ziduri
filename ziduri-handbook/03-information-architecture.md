# 03 — Information Architecture
## Canonical structure
/
 /products/
 /products/<product-slug>/
 /products/<product-slug>/docs/
 /products/<product-slug>/changelog/
 /privacy/<product-slug>/
 /blog/
 /blog/<article-slug>/
 /about/
 /contact/

## URL rules
Lowercase, hyphen-separated, descriptive, stable. Avoid unnecessary dates and query parameters for indexable content. One canonical URL per document. Never change a public URL without a migration/redirect plan.

Core product discovery should be reachable within two clicks from the homepage.
