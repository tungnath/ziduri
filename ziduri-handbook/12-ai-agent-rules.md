# 12 — AI Coding Agent Rules
1. Read README and relevant chapters before implementation.
2. Inspect the existing repository first.
3. Preserve public URLs unless migration is explicitly approved.
4. Never invent product claims, statistics, reviews, certifications, privacy practices or pricing.
5. Keep SEO-critical content in crawlable HTML.
6. Prefer the simplest architecture that satisfies requirements.
7. Reuse design tokens/components.
8. Avoid unnecessary dependencies.
9. Validate accessibility, SEO, links, responsiveness and performance.
10. Update documentation when architecture changes.

Before major changes, report affected files, URL impact, SEO impact, compatibility impact and new dependencies.

Definition of done includes functional, visual, SEO, accessibility, performance, security and documentation validation as applicable.
