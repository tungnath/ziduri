# 05 — Frontend Architecture
Phase 1 uses semantic HTML5, modern CSS and vanilla JavaScript. Core content/navigation must work without JavaScript.

Rules:
- No framework without a concrete reason.
- Keep SEO-critical content in crawlable HTML.
- Use ES modules for behavior.
- Avoid global state and unnecessary dependencies.
- Optimize images/fonts/scripts.
- Lazy-load non-critical media.
- Keep content portable for a future Astro migration.
