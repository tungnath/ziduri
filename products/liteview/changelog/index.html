LiteView release notes

v1.0.0 — July 2026

Initial public release.

  • Native viewing for SVG, WebP and AVIF, plus PNG, JPEG, GIF, BMP and ICO
  • Filmstrip and full grid thumbnail views, lazily loaded and prioritized for what's on screen
  • Zoom at cursor, pan, rotate, fit/1:1, fullscreen, and a pixelated mode past 300% zoom
  • Full keyboard navigation
  • Windows, Linux and macOS packages, each with native install/uninstall scripts
  • Windows and Linux installers register file-type associations for AVIF, WebP and SVG
  • ~2 MB total install size
