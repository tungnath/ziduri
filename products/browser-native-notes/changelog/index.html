Float Note release notes

Float Note is published on the Chrome Web Store. This page tracks every notable change.

v1.0.0 — March 2026

Initial public release, published on the Chrome Web Store.

  • Floating, draggable, translucent note editor
  • Notes keyed by page URL and creation timestamp
  • Auto-save every 2 seconds, with manual save
  • Popup for viewing, resuming, and deleting notes per page
  • Fully local storage via chrome.storage.local — no network requests
