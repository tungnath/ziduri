Make Palette release notes

Notable changes to the palette feed and live preview studio.

Initial public release

September 2026

  • Four-colour feed with newest and popular views.
  • Anonymous likes, local collection and optional account sync.
  • Palette submission with tags, validation, rate limits and moderation.
  • Live previews for ten common web app templates.
  • Role mapping, light/dark modes, contrast notes and token exports.
  • Shareable palette pages and PNG export.

Current boundary

Make Palette is an active product. The public feed and studio are available now; moderation, account delivery and API availability depend on the connected production services. See the documentation and privacy policy for the current implementation details.
