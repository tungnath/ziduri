Make Palette documentation

How to move from a four-colour idea to a tested interface theme.

Browse the feed

The home feed shows approved palettes in newest-first order. Use Popular for month, year or all-time likes, search by tag or colour name, and open a palette to get a stable shareable URL. Hover or click a colour band to copy its hex value.

Open the Preview Studio

Choose Preview in templates from a palette, or open a template directly. The studio includes ten screens: Admin Dashboard, Blog/CMS, CRM, E-commerce Store, Landing Page, Portfolio, Project Management, Social Network, Task/To-do and Travel/Booking.

The URL carries the template and selected palette, so refreshing or sharing the link keeps the same starting point. The left rail lets you reorder or edit swatches, shuffle role mappings and switch light/dark mode. Manual role overrides can be cleared at any time.

Read the generated theme

The theme engine assigns roles such as primary, secondary, accent, highlight and heading. The right rail lists colour tokens and contrast notes. A warning is a prompt to inspect the pairing in context; it is not a claim that every possible text combination is accessible.

Export your work

Choose an export format in the right rail, then copy the output or download it. The studio can also save a PNG of the current template preview. Palette pages can download a palette image and copy a share link. These actions happen in your browser after you request them.

Submit a palette

On Submit, choose exactly four colours and up to five tags. The API validates hex values, rate-limits submissions, checks for exact and perceptual near-duplicates, and places accepted submissions in a moderation queue. A moderator approves or rejects the palette before it appears in the public feed.

Accounts and collection

Likes work anonymously and are kept in this browser. An optional passwordless email link or Google sign-in can sync the collection between devices and show the status of your submissions. See the privacy policy for cookies, storage and third-party services.

Implementation notes

Make Palette's web app is built with Next.js. Its API is a FastAPI service backed by PostgreSQL/pgvector and object storage, with a Redis-compatible queue/cache. The public deployment uses Vercel for the web app and Render, Supabase and Upstash for supporting services. The studio remains useful when the feed API is temporarily unavailable because the template and theme logic run in the browser.
