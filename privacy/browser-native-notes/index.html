Privacy Policy

Float Note Privacy Policy

Effective date: March 2026 · Version 1.0 · Applies to the Float Note browser extension

Float Note does not collect, transmit, or share any personal data. Every note you create stays on your device.

Overview

Float Note ("the Extension") is a floating note editor built into your browser. This policy explains exactly what data the Extension handles, where it lives, and what happens to it.

What data is processed

Float Note processes only what it needs to provide its core feature — a note tied to the page you're on:

  • Note content — the text you type into the editor.
  • Page URL — the address of the page a note is associated with.
  • Timestamp — when each note was created, used as part of its storage key.

Float Note does not collect your name, email address, browsing history beyond the current tab's URL, or any analytics or usage data.

Where data is stored

All data is stored locally using Chrome's chrome.storage.local API. This means:

  • Data stays on your device and is never transmitted anywhere.
  • Data is not synced to any cloud service.
  • Data is not shared with Ziduri, the extension developer, or any third party.

Permissions and why they're needed

PermissionPurpose
storageRead and write notes to local browser storage.
tabsIdentify the current tab's URL so a note can be associated with the right page.
scriptingInject the floating editor interface into the active page.
host_permissions (<all_urls>)Allow the editor to run on any site you choose to take notes on.

Third parties and analytics

Float Note does not use analytics, tracking, advertising networks, or any third-party service. The extension makes no network requests of any kind — it works entirely offline.

Authentication and payments

Float Note has no accounts, sign-in, or payment functionality. There is nothing to authenticate and nothing to purchase.

Data retention and deletion

You control your data directly:

  • Delete an individual note from the extension popup.
  • Use "Clear All" in the popup to remove every note for the current page.
  • Uninstalling the extension permanently deletes all notes stored by it.

Notes are not deleted automatically and persist until you remove them or uninstall the extension.

Your rights

Because all data stays on your device and Ziduri never receives or stores it, there is no remote copy of your notes for us to access, export, or delete on your behalf — deletion happens locally, through the extension itself.

Changes to this policy

If Float Note's data practices change — for example, if a future version adds optional sync — this policy will be updated first, and the version and effective date above will change accordingly.

Contact

Questions about this policy can be sent through the contact page.
